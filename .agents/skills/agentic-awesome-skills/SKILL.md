# 🧠 Agentic Awesome Skills (AAS Hub)

Central de governança e catálogo com mais de **2.100 skills de IA** desenvolvidas pela comunidade e prontas para uso por qualquer um dos 18 agentes do AdShield / LeakFinder.

---

## ⚡ Comandos Rápidos

### 1. Pesquisar Skills no Catálogo
Para buscar qualquer especialidade (ex: `shopify`, `sankhya`, `security`, `wcag`, `cro`, `react`, `supabase`):
```bash
node .agents/skills/agentic-awesome-skills/search.mjs <palavra-chave>
```

### 2. Ativar / Instalar uma Skill no Projeto
Para trazer uma skill da biblioteca para a pasta principal de skills ativas do workspace:
```bash
node .agents/skills/agentic-awesome-skills/install.mjs <nome-da-skill>
```
